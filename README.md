# 온기 마을회관 (실시간 마당)

로그인 없이 주소만 열면 캐릭터가 생기고, 화살표 버튼·마당 터치·방향키로 움직이며 같은 마당의 사람들과 인사를 나누는 웹 서비스예요.
안드로이드, 아이폰, 컴퓨터 어디서든 브라우저로 열려요.

## 구성

| 파일 | 역할 |
| --- | --- |
| `server.js` | 접속 서버. 방 배정, 이름 자동 부여, 이동·인사 중계 |
| `public/index.html` | 화면 전체(마당, 명상, 상담 예약 안내, 소개). 서버가 없으면 시연 모드로 열려요 |
| `test/sim.js` | 가상 접속자 테스트 (`npm test`) |

## 내 컴퓨터에서 실행 (Windows 포함)

1. Node.js 18 이상을 설치해요 (https://nodejs.org).
2. 이 폴더에서 터미널을 열고 아래를 입력해요.
   ```
   npm install
   npm start
   ```
3. 브라우저에서 `http://localhost:3000` 을 열어요. 창을 두 개 열면 서로 보여요.
4. 같은 와이파이의 폰으로 보려면 컴퓨터 IP(예: `http://192.168.0.10:3000`)를 폰 브라우저에 입력해요.
   (윈도우 방화벽이 물어보면 허용해요.)

## 인터넷에 올리기 (누구나 들어오게 하기)

Node 서버와 WebSocket을 지원하는 호스팅이면 어디든 올릴 수 있어요. 예: Render, Railway, Fly.io 등.
무료 플랜 조건(잠자기, 동시 접속, 사용 시간)은 바뀌므로 올리기 전에 해당 서비스에서 확인하세요.

공통 설정은 아래와 같아요.

- 시작 명령: `npm start`
- 설치 명령: `npm install`
- 포트: 호스팅이 주는 `PORT` 환경변수를 자동으로 사용해요.
- 주소는 `https://` 로 열리고, 화면이 알아서 `wss://` 로 연결해요.
- 올린 뒤 `주소/healthz` 가 `ok` 를 보여주면 서버가 정상이에요.

### GitHub를 거쳐 올리는 방법 (Render 예시)

1. 이 폴더를 GitHub 저장소에 올려요. (`node_modules` 폴더는 올리지 않아요.)
2. Render에서 New > Web Service > 그 저장소를 선택해요.
3. Build Command에 `npm install`, Start Command에 `npm start` 를 넣고 만들어요.
4. 배포가 끝나면 나오는 주소를 발표 자료와 QR 코드에 넣어요.

## 인원 설정

환경변수로 바꿔요.

| 이름 | 기본값 | 뜻 |
| --- | --- | --- |
| `ROOM_CAP` | 30 | 한 마당(방)에 들어가는 최대 인원 |
| `MAX_ROOMS` | 50 | 열 수 있는 마당 개수. 전체 최대 인원 = ROOM_CAP x MAX_ROOMS |

- 마당이 가득 차면 새 마당이 자동으로 열려요. 전체가 가득 차면 "마당이 가득 찼어요" 안내가 나와요.
- `주소/stats` 에서 지금 방 개수와 접속자 수를 볼 수 있어요.
- 같은 마당 사람이 늘수록 한 사람이 받는 메시지가 늘어서, 시니어 대상이라면 `ROOM_CAP` 을 10~20 정도로 줄여 한 마당을 작게 두는 것을 권해요.

## 안전 장치 (1단계)

- 자유 입력 채팅이 없어요. 정해진 9개 문장의 번호만 서버가 받아서 전달해요. 그 밖의 내용은 버려요.
- 인사는 1.5초에 한 번만 보낼 수 있고, 좌표는 마당 범위 안으로 서버가 조정해요.
- 이름과 연락처를 받지 않아요. 이름은 서버가 자동으로 붙여요.
- 상담 예약 화면은 시연용이에요. 실제 접수와 개인정보 처리는 협력 기관과 정한 뒤에 붙여요.

## 화면 문구나 문장 바꾸기

`public/index.html` 안 `PHRASES`(문장), `LOOKS`(캐릭터 모습)를 고쳐요.
문장 개수를 바꾸면 `server.js` 의 `PHRASE_COUNT`, 모습 개수를 바꾸면 `LOOK_COUNT` 도 같은 숫자로 맞춰야 해요.

## 확인된 것과 아직 확인하지 못한 것

- 가상 접속자 300명(방 10개)이 모두 초당 10번 움직이는 상황에서 일반적인 개발용 서버 한 대로 문제없이 동작했어요.
- 이 측정은 개발 환경에서 한 것이라, 무료 호스팅에서는 성능이 낮을 수 있어요. 발표 전에 실제 주소로 여러 폰을 접속해 보세요.
